## 🧭 语义目标导航

**从物体语义到机器人运动。** SKG-Nav 面向本地化定制室内场景，将语义目标转化为像素目标，通过扩散模型生成候选轨迹，结合轨迹筛选与底层运动策略完成导航执行。

**技术重点：** 语义分割、扩散规划、分层控制、Isaac Sim、仿真数据流水线。

[查看项目介绍与展示 →](./SKG-nav/)

## 🦾 VLA 双臂操作

**从通用操作策略到模块化设备任务。** 以 XR0 为基座，在 RoboTwin 中开展任务微调，并面向自定义模块化设备场景进行双臂操作适配与真机实验。

**技术重点：** VLA 模型适配、RoboTwin、双臂协作、模块拆卸、仿真与真实平台。
